# SshOneClick

SshOneClick - небольшая утилита для Windows 10, которая настраивает безопасный SSH-доступ к компьютеру в локальной сети.

Приложение:

- запрашивает права администратора через UAC;
- устанавливает встроенный компонент Windows OpenSSH Server, если он отсутствует;
- принимает подключения только по публичному ключу;
- открывает порт `2222` только для частной локальной сети;
- запрещает парольную аутентификацию, перенаправление портов и SSH-агент;
- позволяет отключить созданный SSH-доступ из того же окна;
- сохраняет отчёт `SSH-connection.txt` рядом с исполняемым файлом.

Утилита не изменяет уже существующую конфигурацию OpenSSH: если она обнаружена, настройка прекращается.

## Требования

- Windows 10 версии 1809 (сборка 17763) или новее;
- локальная учётная запись администратора;
- включённый брандмауэр Windows;
- подключение к доверенной локальной сети.

## Сборка

Установите Go версии, указанной в `go.mod`, затем выполните:

```powershell
go build -o SshOneClick.exe .
```

Скрипт `setup.ps1` и публичный ключ `netbook_key.pub` встраиваются в исполняемый файл во время сборки. Приватный ключ `netbook_key` в репозиторий не добавляется и должен храниться только у пользователя, который подключается к настроенному компьютеру.

## Использование

1. Запустите `SshOneClick.exe` на целевом компьютере.
2. Подтвердите запрос UAC.
3. При необходимости подтвердите перевод доверенной сети из общедоступной в частную.
4. Скопируйте команду подключения из окна или файла `SSH-connection.txt`.
5. Для отключения доступа введите `D` в окне утилиты.

Подключение выполняется с другого компьютера командой вида:

```powershell
ssh -i netbook_key -p 2222 USER@IP_ADDRESS
```

Не публикуйте приватный ключ и созданные отчёты о подключении.
